Конвертер температур на Tkinter и PyQt6.

Запуск:

Tkinter: python tkinter_app.py (отдельной установки не требует)
PyQt6: pip install PyQt6, затем python pyqt_app.py

Оба приложения написаны через класс App с методом-обработчиком go и запускаются через if __name__ == "__main__". Температуры: celsius, fahrenheit, kelvin. Преобразование идёт через градусы Цельсия: to_c переводит исходное значение в Цельсий, from_c переводит из Цельсия в нужную шкалу, поэтому вложенных if для каждой пары нет.

Как выполнены 10 требований задания:

Главное окно: в Tkinter это tk.Tk(), в PyQt это класс App(QWidget). Заданы заголовок и размер 350x250.
Текстовые элементы: tk.Label и QLabel для подсказки и для вывода результата.
Поле ввода: tk.Entry и QLineEdit. Дробные числа можно вводить и с запятой, и с точкой.
Кнопки: «convert» (tk.Button и QPushButton) и дополнительная кнопка «swap», которая меняет шкалы местами.
Выбор параметров: два выпадающих списка (ttk.Combobox и QComboBox) для исходной и целевой шкалы.
Вывод результата: результат выводится в Label с округлением до двух знаков, например result: 212.00 fahrenheit.
Обработка событий: кнопки привязаны к методам go и swap (command= в Tkinter, clicked.connect в PyQt). Расчёт запускается и по клавише Enter в поле ввода (bind("<Return>") и returnPressed.connect).
Проверка данных: ввод преобразуется в число внутри try/except ValueError. Дополнительно отсекаются nan и inf (через math.isfinite), а также температуры ниже абсолютного нуля (-273.15 C).
Диалоговое окно: при любой ошибке показывается окно с сообщением (messagebox.showerror и QMessageBox.warning).
Компоновка: в Tkinter используется менеджер grid. В PyQt используются QVBoxLayout (общая вертикальная раскладка) и QHBoxLayout (ряд со списками и ряд с кнопками).
