Игра «Побег из пещеры»

Цель:

Найти 3 кристалла и дойти до выхода, пока не закончилась энергия.

Правила:

Пещера — поле 6x6. Вы начинаете в левом верхнем углу (0, 0).
Начальная энергия — 25. Каждый шаг тратит 1 энергию.
Если энергия дошла до 0 (и вы не на выходе), игра проиграна.
Хождение в стену энергию не тратит.
Выход открывается только после сбора всех 3 кристаллов. Если пришли
без них, можно уйти искать дальше и вернуться позже.
Победа даёт очки: стоимость всех предметов в инвентаре + 100 за
каждый кристалл.

Типы комнат:

Пустая: ничего не происходит.
Кристалл: даёт 1 кристалл (нужно собрать 3).
Лагерь: восстанавливает 10 энергии.
Сундук: 1-2 случайных предмета.
Ловушка: отнимает 6 энергии. Если в инвентаре есть верёвка, она
тратится, а ловушка не срабатывает.
Выход: победа, если собраны все кристаллы.

Комнаты срабатывают только при первом посещении (кроме выхода).

Предметы:

food: восстанавливает 8 энергии (use food)
torch: показывает типы комнат вокруг вас, включая диагонали
(use torch), результат виден по команде map
rope: автоматически спасает от одной ловушки
coin: даёт очки (стоимость 50)
rock: тяжёлый мусор без ценности

Грузоподъёмность инвентаря — 12. Если предмет из сундука не влезает,
он остаётся в сундуке.

Команды:

w / a / s / d  - движение (вверх, влево, вниз, вправо)
map            - карта пещеры (? неизвестно, . посещено, - пусто,
                 C кристалл, F лагерь, B сундук, T ловушка, E выход)
i              - инвентарь
use <имя>      - использовать предмет (food или torch)
drop           - выбросить последний предмет
remove <имя>   - выбросить предмет по названию
srt val / wt   - сортировка инвентаря по цене / весу
rev            - перевернуть порядок инвентаря
slice <a> <b>  - показать часть инвентаря (срез)
top            - 3 самых ценных предмета (без изменения инвентаря)
h              - помощь
q              - выход
