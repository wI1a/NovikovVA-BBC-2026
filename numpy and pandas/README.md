Анализ данных Titanic (Pandas и NumPy)
 
Инструкция по работе с программой.
 
Назначение
 
Программа загружает файл train.csv, обрабатывает пропуски, выполняет
расчёты средствами NumPy, фильтрует и группирует данные средствами Pandas
и сохраняет результаты в файлы. Сообщения и названия столбцов в выводе
на английском языке.
 
Установка и запуск
 
1. Установить библиотеки:
 
   pip install pandas numpy
 
2. Поместить файл train.csv в одну папку со скриптом.
 
3. Запустить скрипт:
 
   python titanic_pandas_numpy.py
 
Файлы
 
- titanic_pandas_numpy.py — код программы
- train.csv — исходные данные (должен находиться рядом со скриптом)
- clean.csv — таблица после обработки (создаётся при запуске)
- stats.csv — статистика по классу и полу (создаётся при запуске)
 
Порядок работы программы
 
После запуска программа запрашивает количество первых строк для вывода (n).
Если введено не число, выводится сообщение "error: incorrect input, n = 5"
и используется значение n = 5. Дальнейший ввод не требуется: части со 2 по 7
выводятся подряд, каждая под своим заголовком, например
"part 3. missing values".
 
Части
 
2. Загрузка и первичный анализ: head, tail, размер таблицы, типы столбцов,
   статистика числовых признаков, количество пассажиров по классам.
3. Пропуски: подсчёт и процент пропусков, заполнение Age медианой,
   заполнение Fare медианой своего класса, удаление строк без порта
   посадки, удаление столбца Cabin (если пропусков больше 50%) с
   добавлением признака HasCabin.
4. NumPy: выживаемость, возраст по полу, статистика и квартили Fare,
   стандартное отклонение, выбросы по z-оценке, гистограмма возраста,
   корреляция класса и цены билета.
5. Фильтрация: пять условий (И, ИЛИ, isin, between, str.contains).
6. Группировка: по классу и полу, по порту посадки, по возрастным группам,
   по признаку "один / с семьёй", определение лучшего класса, сводная
   таблица.
7. Сохранение результатов в clean.csv и stats.csv и проверка повторной
   загрузки.
 
Возможные ошибки
 
- Если файл train.csv не найден, выводится сообщение "error: ... not found",
  и программа завершается. Необходимо проверить расположение файла и
  запустить скрипт повторно.
- Результаты сохраняются в ту же папку, где находится скрипт.
 
Особенности данных
 
Файл train.csv из этого набора содержит 418 строк (PassengerId 892-1309).
Значения столбца Survived в нём полностью совпадают с полом: у всех женщин 1,
у всех мужчин 0. Поэтому в выводе выживаемость женщин составляет 100%,
мужчин 0%, а для групп без пассажиров (например, выжившие мужчины) средний
возраст не вычисляется и выводится "n/a". Для полного набора на 891 строку
значения будут другими.
