Методы строк

Учебная программа по методам строк в Python. Пять уровней, на каждом
разбирается своя группа методов с тестами и возможностью ввести свои
данные. Подсказки и сообщения в программе на английском.

Запуск

python main.py

Уровни

1. upper(), lower(), capitalize()
2. find(), replace(), count()
3. split(), join()
4. isdigit(), isalpha(), strip(), format()
5. нормализация текста (чистка мусорных символов, пробелов и т. д.)

Файлы

- main.py — меню, выбор уровня, запуск нужного модуля
- lvl1.py ... lvl5.py — по одному уровню на файл
- функция normalize_text для пятого уровня лежит в lvl5.py

Как пользоваться

Запускаете main.py, вводите номер уровня от 1 до 5. Дальше программа
показывает описание методов, прогоняет тестовый пример и просит ввести
свои данные. Формат ввода написан прямо в подсказке перед вводом.

На первом уровне надо ввести строку и номер метода через запятую
с пробелом (1 - upper, 2 - lower, 3 - capitalize):

hello world, 1

Результат: HELLO WORLD

На втором уровне всё вводится одной строкой, аргументы идут через точку
с запятой и пробел. Названия методов пишутся по-английски:

Very cool; find; cool

Результат: 5 (индекс первого совпадения)

Very cool; replace; cool; nice

Результат: Very nice

На третьем и четвёртом уровне сначала вводится номер метода, а затем
программа отдельными вопросами просит строку, разделитель, шаблон или
значения. Элементы списка и значения для format() пишутся через
точку с запятой и пробел, например: Anna; 20. Если на вопрос про
разделитель или символы для strip() просто нажать Enter, используются
значения по умолчанию (пробельные символы).

На пятом уровне вводится только строка, программа выводит её
нормализованный вариант.

Если ввод не подходит по формату, программа пишет "error: ..." (например,
"error: incorrect input", "error: not enough args" или
"error: no such method") и завершается. Чтобы попробовать ещё раз,
нужно запустить main.py заново.
