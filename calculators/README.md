ДЗ 1: Калькулятор
 
В проекте представлены четыре независимых файла с реализацией калькулятора.
Каждый файл демонстрирует отдельный подход к написанию программы.
Сообщения программы выводятся на английском языке.
 
Запуск
 
Каждый файл запускается отдельно из командной строки:
 
python calculator_all_in_main.py
python calculator_calc_in_def.py
python calculator_operands_are_def_calc_in_main.py
python calculator_class.py
 
Правила ввода
 
Программа поочерёдно запрашивает числа и оператор (+, -, *, /). При
неверном вводе выводится сообщение "error: incorrect input", при делении
на ноль - "error: division by zero", после чего работа продолжается.
Команда 'q' завершает программу.
 
Описание файлов
 
1. calculator_all_in_main.py (Последовательный подход)
Реализация на основе линейного кода. Отсутствуют функции и классы.
Все инструкции выполняются в основном потоке внутри цикла while.
Результат каждой операции становится первым числом следующей, как на
обычном калькуляторе: 2 + 3 даёт 5, затем * 4 даёт 20. Ввод '=' на месте
оператора сбрасывает результат и запрашивает новое первое число.
 
2. calculator_calc_in_def.py (Подход через 1 функцию и while)
Вся логика программы находится в одной функции start_calculator. Внутри
неё используется бесконечный цикл while, который позволяет выполнять
вычисления многократно без перезапуска. Каждое вычисление независимо:
запрашиваются первое число, оператор и второе число. Выход из программы
осуществляется командой 'q' при вводе первого числа. Для запуска в конце
файла должен находиться вызов start_calculator().
 
3. calculator_operands_are_def_calc_in_main.py (Операции через функции)
Для каждой математической операции (сложение, вычитание, умножение,
деление) создана отдельная функция: add, sub, mul, div. Сам калькулятор
(цикл и ввод данных) находится в основном потоке, вне функций. Работает
в последовательном режиме, как файл из пункта 1. Проверка деления на
ноль выполняется в цикле перед вызовом функции div.
 
4. calculator_class.py (Подход через класс)
Объектно-ориентированный подход. Создан класс Calculator, содержащий
методы для арифметических операций (add, sub, mul, div) и метод run для
взаимодействия с пользователем через консоль. Деление на ноль
обрабатывается через исключение ZeroDivisionError, которое
перехватывается в методе run. Работает в последовательном режиме,
как файл из пункта 1.
